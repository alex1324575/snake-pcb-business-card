# Exported review files

| Files | Scope |
|---|---|
| [SnakeCard_RevC_Schematic.pdf](SnakeCard_RevC_Schematic.pdf) | Current native Altium Rev C single-sheet schematic; publication removes author metadata without flattening the page. |
| `SnakeBusinessCard_Schematic.pdf`, `SnakeBusinessCard.net.xml` | Historical root KiCad circuit exports. |
| `SnakeBusinessCard_BOM.csv`, `Procurement_BOM.csv` | Historical KiCad purchasing selections; not the Rev C BOM. |

For Rev C use the [controlled BOM](../docs/revc/assembly/BOM.md), [assembly drawings](../docs/revc/assembly/ASSEMBLY_REFERENCE.html), [fabrication files](../fabrication/revc/) and [verification records](../verification/revc/). The [publication manifest](../verification/revc/PUBLICATION_MANIFEST.json) maps the checked engineering files to public copies.

Do not combine exports from different revisions. Regenerating the historical KiCad exports does not update the native Altium design or its reports. No physical hardware result is established by these documents.
