# Rev C engineering documents

Use this directory with [the Rev C Altium project](../../altium/SnakeCard_RevC.PrjPcb) and [matching Gerber/NC files](../../fabrication/revc/). Earlier KiCad outputs describe a different revision.

1. Review the [circuit PDF](../../exports/SnakeCard_RevC_Schematic.pdf), [corrective-action record](REVIEW.md) and [layout tradeoffs](LAYOUT_TRADEOFFS.md).
2. Check the [controlled BOM](assembly/BOM.md), [placement register](assembly/PLACEMENT_REGISTER.md), [assembly drawings](assembly/ASSEMBLY_REFERENCE.html) and [manual](assembly/ASSEMBLY_MANUAL.md).
3. Confirm [fabrication requirements](FABRICATION_NOTES.md) with the supplier.
4. Assemble one first article and complete the [qualification plan](electrical/QUALIFICATION_PLAN.md).

CAD validation and final CAM review are complete. Supplier acceptance and physical qualification remain open. Publication provenance and exact file hashes are in the [verification directory](../../verification/revc/).
