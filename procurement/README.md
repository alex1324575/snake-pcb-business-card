# Procurement records

The current prototype selection is **Altium Rev C / SC-REVC-LCSC-P1**. Use the [controlled Rev C BOM](../docs/revc/assembly/BOM.md), [CSV](../docs/revc/assembly/BOM.csv) and [component register](../docs/COMPONENT_REVIEW.md).

`parts.json` describes the historical KiCad selection. The root procurement scripts synchronize that KiCad design and earlier exports; they do not update the native Altium Rev C files. In particular, the historical U3/D91 selection and capacitor families are not the current purchasing specification.

Supplier links identify exact parts, not reserved inventory or an approved substitute. Record received manufacturer/order codes, lots and markings before assembly. See the [current assembly manual](../docs/revc/assembly/ASSEMBLY_MANUAL.md) and [qualification record](../docs/revc/electrical/QUALIFICATION_PLAN.md). All physical tests remain NOT TESTED.
